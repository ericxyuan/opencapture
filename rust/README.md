# Rust migration

This directory contains components being ported from the existing C# application. It does not yet provide a replacement application. The existing application and its build remain unchanged.

The MJPEG AVI writer preserves the existing format and requires pre-encoded JPEG frames. Call `finish` and handle its result to finalize the recording; dropping an unfinished writer leaves an incomplete file. The reader streams the encoded frames and does not yet decode or crop them. The shortcut module parses and serializes the existing Windows Forms shortcut format; it does not read the registry or register hotkeys yet.

Run `cargo test` with a Rust toolchain. The recording compatibility test compares output byte-for-byte against a fixture generated by the C# `MjpegAviWriter`.
