# Rust migration

This directory contains components being ported from the existing C# application. It does not yet provide a replacement application. The existing application and its build remain unchanged.

The capture module provides a GDI virtual-desktop snapshot, pixel access and cropping in physical coordinates. The caller must enable per-monitor-v2 DPI awareness; HDR conversion and the selection overlay are not implemented.

The recording module encodes frames as MJPEG and provides an SDR GDI capture worker. Output must stay in a private pending location until accepted. Call `finish` on a recording writer, or `stop` on its worker, and handle errors to finalize the file. The reader streams the encoded frames and does not yet decode or crop them. The worker does not yet support HDR, a recording border or capture exclusion.

The OCR module runs the Windows engine for the user's preferred language on a worker thread. It does not yet implement the original's multiple language and image-enhancement passes. The review module contains countdown and acceptance rules but no interface or save/clipboard handling. The shortcut module parses and serializes the existing Windows Forms shortcut format; it does not read the registry or register hotkeys yet.

No Rust desktop application exists yet. Menus, precision panel, zone detection, HDR, review and save/clipboard integration, recording review and cropping, and the remaining OCR processing must be migrated and tested before feature parity or a whole-app performance comparison can be claimed.

Run `cargo test` with a Rust toolchain. The recording compatibility test compares output byte-for-byte against a fixture generated by the C# `MjpegAviWriter`.

`cargo run --release --example benchmark_capture` measures only the Rust SDR GDI desktop snapshot and pixel-buffer copy. On 15 November 2026, a local run over a 5120×1600 virtual desktop, with five warmups and 30 samples, produced a 50.52 ms median and 57.31 ms p95. This does not include HDR replacement, interface, OCR, review or saving, and is not a comparison with the C# application.
